# Gestión de Pedidos

## Descripción

Este proyecto consiste en un sistema de gestión de pedidos desarrollado en Java.

El objetivo es aplicar conceptos de Programación Orientada a Objetos mediante la creación de clases que representan los diferentes elementos involucrados en la gestión de pedidos y la interacción entre ellos.

## Funcionamiento

El sistema permite representar y gestionar pedidos mediante objetos.

La lógica del programa se basa en la comunicación entre las diferentes clases, donde cada objeto tiene sus propios atributos y métodos para realizar las operaciones correspondientes.

## Estructura del proyecto

El proyecto está organizado utilizando una estructura de proyecto Java en IntelliJ IDEA:

```text
gestionPedidos/
├── .idea/
├── src/
├── .gitignore
└── gestionPedidos.iml
```

La carpeta `src` contiene el código fuente del programa.

## Conceptos utilizados

En este ejercicio se aplican conceptos fundamentales de Programación Orientada a Objetos:

* Clases y objetos.
* Atributos.
* Métodos.
* Constructores.
* Encapsulamiento.
* Getters y setters.
* Asociación entre clases.
* Comunicación entre objetos.
* Uso de referencias a objetos.

## Ejecución

El proyecto puede ejecutarse desde **IntelliJ IDEA**:

1. Abrir el proyecto `gestionPedidos`.
2. Ingresar a la carpeta `src`.
3. Abrir la clase que contiene el método `main`.
4. Ejecutar el programa utilizando el botón **Run**.
5. Verificar los resultados en la consola de IntelliJ.
